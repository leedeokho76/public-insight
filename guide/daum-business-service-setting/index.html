다음 비즈니스 서비스(티스토리 및 다음스마트워크) 이용을 위한 환경설정

2024-08-07
saas
  • 1. 티스토리 서비스에 외부 도메인 연결을 위한 환경설정
  • 2. 다음 스마트워크 이용을 위한 환경설정
  • 【참고자료】

1. 티스토리 서비스에 외부 도메인 연결을 위한 환경설정

  1. 도메인 네임 서비스회사에서의 DNS 설정
    • DNS 레코드 설정 창에서 다음 2개의 DNS 레코드 설정 추가
      호스트 이름 유형 값
      @ A 27.0.236.139
      www CNAME host.tistory.io
  2. 티스토리에서의 설정
    • 관리 → 블로그 → 개인 도메인 설정
  3. 메인 도메인을 2차 도메인으로 리디렉션
    • html head 태그 내에 다음 코드 삽입
    <!-- 리디렉션 시작 -->
<script type-"text/javascript">
  var url1 = 'duqe.tistory.com'; // 티스토리 계정
  var url2 = 'duqe.kr'; // 개인 도메인
  var online = document.URL;
  if (online.match(url1)) document.location.href = online.replace(url1, url2);
</script>
<!-- 리디렉션 끝 -->

2. 다음 스마트워크 이용을 위한 환경설정

  1. 도메인 네임 서비스회사에서의 DNS 설정
    • DNS 레코드 설정 창에서 다음 2개의 DNS 레코드 설정 추가
      호스트 이름 유형 값
       @ MX 10 aspmx.daum.net
      @ MX 20 alt.aspmx.daum.net
      @ TXT v=spf1 include:_spf.daum.net ~all
  2. 비즈니스 메일 설정
    • 다음메일 로그인 - 다음 스마트워크
  3. 확장 메일 클라이언트 설정
     구분 Server Port
     POP3 pop.daum.net 995
    IMAP imap.daum.net 993
    SMTP smtp.daum.net 465
  4. 메일 클라이언트 설정
    • 메일주소: 스마트워크에서 사용하는 기관/단체 메일주소
    • 로그인아이디: 다음 로그인 아이디
    • 패스워드: 앱 비밀번호(2025년 1월 2일 이후 적용), 디바이스마다 생성
