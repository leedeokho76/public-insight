1. 설치환경 구성

  1. Linux 부팅usb 제작
  2. usb 부팅
    • 노트북 등 몇몇 하드웨어에서 부팅순서 변경을 위한 BIOS Setup 진입이 불가능한 경우, 부팅usb를 꼽고 윈도우 로그인 상태에서 shift키+다시시작을 클릭하면 부팅 디바이스를 선택할 수 있는 상태로 전환

2. Linux 설치 순서

  1. 언어선택 및 체험·설치 옵션 선택
  2. 키보드 레이아웃 선택
  3. 업데이트 및 기타 소프트웨어
    • 일반설치 vs 최소설치
    • Ubuntu 업데이트 다운로드 및 서드파티 소프트웨어 선택 옵션
  4. 설치형식
    • 기존 OS 삭제 여부 선택
    • 디스크 파티션 설정 과정
  5. 시간대 설정
  6. 계정명 및 네트워크명 등 설정

3. 원격데스크톱 접속 설정

  1. Linux에 xrdp 설치 및 설정 
    $ sudo apt update
$ sudo apt install xrdp -y
$ sudo systemctl enable xrdp  //시작시 자동실행
$ sudo systemctl start xrdp
  2. 서버측 ip주소 확인 
    $ ip addr
  3. xfce 데스크톱 설치 및 설정 
    $ sudo apt install xfce4
$ echo "startxfce4" > ~/.xsession  //환경변수 등록 ~/.xinitrc 파일로도 시도
$ dpkg -l | grep xfce4  //xfce 설치확인
$ sudo systemctl restart xrdp
$ ls -l ~/.xsession  //일반 사용자 계정으로 접속 가능한지 확인
$ cat /var/log/xrdp-sesman.log  //오류확인
$ cat /var/log/xrdp.log  //오류확인
  4. startwm_sh 내용 변경(2번 실패시) 
    $ sudo nano /etc/xrdp/startwm_sh
#test -x /etc/x11/xsession && exec /etc/x11/xsession  //기존내용 주석처리
#exec /bin/sh /etc/x11/xsession  //기존내용 주석처리
test -x /usr/bin/startxfce4 && exec /usr/bin/startxfce4
exec /bin/sh /usr/bin/startxfce4
  5. 방화벽 포트 허용 
    $ sudo ufw allow 3389/tcp

4. SSH 접속 설정

  1. SSH 서버 설치 
    $ sudo apt update
$ sudo apt install openssh-server -y
$ sudo systemctl status ssh  //서비스 상태 확인
  2. 서버측 ip주소 확인 
    $ ip addr
  3. 클라이언트에서 접속 및 확인 
    $ ssh 사용자명@IP주소
$ whoami  //계정정보
$ hostname  //호스트정보
