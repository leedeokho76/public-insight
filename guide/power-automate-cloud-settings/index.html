2. 로컬PC 설정

2.1. Windows 사용자 계정 추가 및 조직 계정으로 로그인

  1. 설정 → 계정 → 회사 또는 학교 엑세스
  2. 계정 추가시 표시되는 이 디바이스를 Microsoft Entra ID에 가입으로 로그인
  3. 현재 로컬 계정 로그아웃 후, 반드시 *조직계정(id@organization.com)*으로 로그인

2.3. Power Automate Machine Runtime 설치 및 디바이스 등록

  1. 머신환경 및 머신그룹 설정
  2. 문제해결 메뉴에 진단도구 실행으로 상태 확인

3. 클라우드 설정

3.1. PowerAutomate 온라인 등록 확인

  1. PowerAutomate Portal 접속
  2. 메뉴 중 Machines 항목에 머신 런타임에 등록된 머신 확인

3.2. 새 연결 생성

  • 온라인 흐름을 만드는 과정에서 새 연결을 생성
    1. 사용자 이름 및 암호로 연결 - Attended 모드(유인 실행)용 조직계정 아이디/패스워드
    2. 로그인하여 연결 - 유인(프리뷰)
    3. 서비스 주체와 자격 증명으로 연결 - Unattended 모드(무인 실행)용
