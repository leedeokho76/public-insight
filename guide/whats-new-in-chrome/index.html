크롬 시작시 새로운 기능 안내창 열림 해제

2024-09-18 (Last updated: 2026-02-26)
application
  • 1. 설정변경
  • 2. 문제가 해결되지 않는 경우
  • 【참고자료】

1. 설정변경

  • 주소입력창에 chrome://flags/ 입력
    • Input “chrome://flags/” in URL bar
  • Show Chrome What’s New page at chrome://whats-new 항목 찾기
    • Find “Show Chrome What’s New page at chrome://whats-new”
  • 기본값을 사용않함으로 변경
    • Change Default to Disable

2. 문제가 해결되지 않는 경우

  • 설정변경후에도 같은 증상이 반복되면 버전문제이므로 브라우저를 제거하고 PC 리부팅 후 다시설치 필요
    • If it doesn’t change in spite of the above task, uninstall the current version and then reinstall recent version.
