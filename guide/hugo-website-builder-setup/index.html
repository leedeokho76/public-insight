2. 콘텐츠 생성 및 구조

  1. 사이트 생성

    ####### 여기서부터 Powershell 관리자권한 불필요

$ hugo new site .  ####### .은 현재위치에, 문자는 새 디렉터리에 생성
Congratulations! Your new Hugo site was created in D:\dev\www.

Just a few more steps...

1. Change the current directory to D:\dev\www.
2. Create or install a theme:
   - Create a new theme with the command "hugo new theme <THEMENAME>"
   - Or, install a theme from https://themes.gohugo.io/
3. Edit hugo.toml, setting the "theme" property to the theme name.
4. Create new content with the command "hugo new content <SECTIONNAME>\<FILENAME>.<FORMAT>".
5. Start the embedded web server with the command "hugo server --buildDrafts".

See documentation at https://gohugo.io/.

  2. 생성된 디렉토리 구조

    root
│ hugo.toml  ####### 추후 config.toml로 변경
├─archetypes
│   default.md
├─assets
├─content  ####### 정적 콘텐츠 디렉토리
│ └─categories  ####### 여기부터 사용자화
│   └─posts
│       ***.md
│       ***.svg
├─data
├─i18n  //internationalization 여러 언어로 지원할 수 있도록 번역 문자열을 관리
├─layouts
├─static
└─themes

3.2.1. 테마 설치 및 설정

  1. go 언어 설치 확인 미 설치시 https://go.dev/ 에서 다운로드 및 설치

  3. hugo 설정 파일 내용 추가

  4. 테마 모듈 설치 
    $ hugo mod get github.com/imfing/hextra

  1. 설정 파일 수정

    $ hugo mod tidy
# 별도 실행 결과는 표시되지 않고 go.mod` 파일에서 테마 관련 항목이 삭제된 걸 확인
  3. 캐시 비우기 
    $ hugo mod clean
  4. go.sum 파일 삭제

4. 메인 페이지에 카테고리별 최근글 출력 소스

  1. Partial 파일 생성

    ####### layouts/partials/recent-by-category.html
<h2>카테고리별 최근 글</h2>

{{ range $section, $pages := .Site.Sections }}
   {{ $sorted := sort $pages.Pages "Date" "desc" }}
   {{ if gt (len $sorted) 0 }}
      <h3>
         <a href="{{ (index $sorted 0).Section | relURL }}">
         {{ $pages.Section | title }}
         </a>
      </h3>
      <ul>
         {{ range first 5 $sorted }}
         <li>
            <a href="{{ .Permalink }}">{{ .Title }}</a>
            <span class="date">{{ .Date.Format "2006-01-02" }}</span>
         </li>
         {{ end }}
      </ul>
   {{ end }}
{{ end }}

  2. Mainpage에 Partial 삽입

    ####### layouts/index.html
{{ define "main" }}
   {{ .Content }}
   {{ partial "recent-by-section.html" . }}
{{ end }}

  3. 설정 파일에 taxonomy 정의 등록

    [taxonomies]
   tag = "tags"
   category = "categories"
   archive = "archives"

    ####### 최신 버전의 부트스트랩설치시 Hugo의 **내장 SCSS 컴파일러(libSass 기반)**가 최신 Bootstrap 5의 SCSS 함수(to-rgb)를 지원하지 않아 "TOCSS: failed to transform "/scss/bootstrap.scss" (text/x-scss): Function not found: to-rgb" 오류 발생
####### Bootstrap 5는 Dart Sass를 기준으로 작성되었는데, Hugo는 아직 Dart Sass가 아니라 libSass를 쓰고 있어 최신 함수들 인식 불능

6.2. CDN 방식

  • 기본적으로 head.html에 <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.css"> 추가하고, footer.html에 <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>을 추가하면 작동
  • 모듈방식으로 테마 설치한 경우, $ hugo mod vendor 명령을 실행시 프로젝트 폴더애 _vendor 폴더가 생성되고 파일구조 파악가능
  • _vendor 폴더에서 …..partials/head.html과 footer.html 파일을 복사해서 프로젝트/layouts/partials/에 복사하여 소스 추가

7. Github.com에 퍼블리싱용 파일 업로드

7.1. 리포지토리 생성

  • Choose visibility: public 선택해야 정적 호스팅 가능
  • Add README: 사이트 설명용 파일
  • Add .gitignore: push 제외할 폴더 선택 옵션으로 추후 로컬에서 설정가능
  • Add license: 선택옵션

7.2. 로컬에서 push

  1. 호스팅할 파일이 있는 경로로 이동 
    $ cd public
  2. 폴더 초기화 
    $ git init
Initialized empty Git repository in D:/OneDrive/dev/public-re-kr/public/.git/
  3. 로컬 디렉터리와 원격저장소 연결 
    $ git remote add origin https://github.com/username/project-site.git
  4. 새 브랜치를 생성하고 그 브랜치로 이동 
    $ git checkout -b gh-pages
Switched to a new branch 'gh-pages'
  5. 모든 파일을 스테이징 
    $ git add .
  6. 스테이징한 파일을 커밋 
    $ git commit -m "Deploy Hugo site"
[gh-pages (root-commit) 852ae2c] Deploy First Public Directory
299 files changed, 54843 insertions(+)....
  7. force 옵션시 로컬파일 기준 강제 덮어쓰기 수행(옵션 제거시 변경된 파일만 업데이토) 
    $ git push origin gh-pages --force

10. Hugo의 Go Template 엔진의 활용 요소

  1. 현재 섹션(예: 6월)에 포함된 전체 페이지 수 {{ len $section.Pages }}
  2. 하위 섹션을 제외한 실제 본문 파일들만 카운트 {{ len .RegularPages }}
  3. 하위 디렉토리(분야별 카테고리 등)가 몇 개인지 확인 {{ len .Sections }}
  4. 목록 중 가장 최근에 수정된 날짜를 추출 {{ (index .Pages.ByLastmod.Reverse 0).Lastmod.Format "2006-01-02" }}
  5. 총 단어 수 합계 
    {{ $totalWords := 0 }}
{{ range .Pages }}{{ $totalWords = add $totalWords .WordCount }}{{ end }}
전체 단어 수: {{ $totalWords }}
