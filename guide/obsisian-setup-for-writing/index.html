1. 설치

  • 옵시디언 공식 사이트접속하여 인스톨파일 다운로드

2. 설정 및 커뮤니티 플러그인 설치

  1. 스니펫

    1. /obsidian-root/.obsidian/snippets/user.css 저장
2. 설정→외형→CSS스니펫에 user.css 경로 등록

  2. Markdown Furigana (루비입력)

    - {漢字|かんじ} 배분정렬
- {漢字|かん|じ} 기수정렬

  3. Templater (탬플레이트 자동화)

    1. 아래 내용으로 /obsidian-root/임의폴더/임의파일.md 저장
    <%-* tR += `{${tp.file.selection()}|}` -%>
2. 설정→커뮤니티플러그인→Templater 설정
    - Template folder location: 임의폴더 등록
    - Template hotkeys: 임의폴더/임의파일 등록
3. 설정→단축키
    - Template로 검색 후 단축키 할당

3. 옵시디언에서 가능한 마크다운 문법

범용으로 사용되는 마크다운 문법은 마크다운 문법 사용 개요 참고

3.1. 기본 포멧

문법 내용
[[Link]] Internal links
![[Link]] Embed files
![[Link#^id]] Block references
^id Defining a block
[^id] Footnotes
%%Text%% Comments
Text Strikethroughs
==Text== Highlights
``` Code blocks
- [ ] Incomplete task
- [x] Completed task
> [!note] Callouts
(see link) Tables

3.2. 고급 포멧

  1. 다이어그램 
    sequenceDiagram
    Alice->>+John: Hello John, how are you?
    Alice->>+John: John, can you hear me?
    John-->>-Alice: Hi Alice, I can hear you!
    John-->>-Alice: I feel great!
  2. 수학 
    $$
\begin{vmatrix}a & b\\
c & d
\end{vmatrix}=ad-bc
$$

3.3. Callouts

[!note] > [!note] 파란색, 메모 아이콘

[!abstract] > [!abstract] 녹색의 꿀팁이나 권장 사항

[!info] > [!info] 파란색, 정보 아이콘

[!todo] > [!todo] 파란색, 체크박스 아이콘

[!tip] > [!tip] 초록색, 전구 아이콘

[!success] > [!success] 초록색, 체크 아이콘

[!question] > [!question] 파란색, 물음표 아이콘

[!warning] > [!warning] 주황색, 경고 아이콘

[!failure] > [!failure] 빨간색, X 아이콘

[!danger] > [!danger] 빨간색, 경고 아이콘

[!bug] > [!bug] 빨간색, 벌레 아이콘

[!example] > [!example] 회색, 문서 아이콘

[!quote] > [!quote] 회색, 따옴표 아이콘
