Ableton Live 필수 설정과 작업 팁

2024-08-26 (Last updated: 2026-02-26)
Guide
multimedia

  • 2. 주요 사용자 인터페이스
  • 3. 단축키
  • 4. 권장되는 벨로시티 값
  • 【참고자료】

1. Preference Settings

  • Plug-Ins
    • Use Audio Units v2: On
      • If you’re working only macOS, use this area
    • Use VST3 Plug-In System Folders: On
      • If you’re going to use working file in WindowsOS later, must be worked this Plug-In Area
      • Confirm Categories > Plug-Ins > AUv2 & VST3
  • Record Wrap Launch
    • Create Fades on Clip Edges: Off

2. 주요 사용자 인터페이스

  • Drum Rack: 한 버튼으로 한 음원 재생
  • Instrument Rack: 버튼을 피아노건반으로 세분. DrumRack 뒤에 위치
  • MIDI Effects > Random: 버튼 하나로 무작위적인 피아노 건반 접근. Drum Rack 과 Instrument Rack 사이에 위치
  • MIDI Effects > Note Length: 노트길이 조정. Instrument Rack 뒤에 위치
  • Live mode & Programmer mode Change: 세션버튼 길게 눌러 설정 상태에서 오른쪽아래 녹색버튼은 라이브모드, 주황버튼은 프로그래머모드 설정
  • Media Effect 내에 Media Effect를 넣고 그 Media Effect 내에 다른 기능들을 추가할 수 있음

3. 단축키

  • TAB: change workspace
  • command shift T: new midi Track
  • command T: new wave Track
  • command D: Duplicate
  • command L: Loop on/off
  • command E: splitE
  • command shift F: Follow ( Arrangment View의 재생위치 따라감.)
  • shift spacebar: play from stop position
  • command K: Key map mode
  • command M: Midi map mode
  • command opt W: broWser
  • command opt G: Groove pool
  • command opt L: device
  • command F: Find
  • command R: collections
  • command shift W: vieW
  • command shift M: clip
  • command opt E: clip view Expand

4. 권장되는 벨로시티 값

  • Kick: 80~100
  • Rimshot: 85~105
  • Snare, Clap, Openhihat, Crashcymbal: 85~105
  • Closedhihat, Ridecymbal: 60~80
