# 아래아한글 일본어 입력설정

## 글자판 변경

입력기 환경 설정 ( Alt + F2 )

- 현재글자판: 일본어
- 제1글자판: 윈도우입력기
- 제2글자판: 윈도우입력기

## 글자판 변경시 오류 발생

- 구버전 아래아한글 삭제 후 일어나는 오류임.
- 메모장(관리자권한)에서 "C:\Windows\hjimesv.ini"를 열어 경로에 새로 설치한 버전의 path로 수정

## 요미가나 입력

언어선택사항 ( Shft + F3 )

- 확장 문자 입력 형식: 요미가나를 위 덧말로
- 요미가나 문자종류: 히라가나

## 글자입력

- ん: nn
- 요음: x a, x i, x u, x e, x o
- 촉음(っ): x t u 또는 っ 다음에 오는 자음 두번
