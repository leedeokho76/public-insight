# Github에서 마크다운 문법의 사용

## 1. 제목

```
# A first-level heading
## A second-level heading
### A third-level heading
#### A fourth-level heading
##### A fifth-level heading
###### A sixth-level heading
```

# A first-level heading

## A second-level heading

### A third-level heading

#### A fourth-level heading

##### A fifth-level heading

###### A sixth-level heading

## 2. 텍스트 스타일

```
**굵게** 또는 __굵게__
*이탤릭체* 또는 _이탤릭체_
~~취소선~~
**굵게 일부 _이탤릭체_**
***모두 굵게 이탤릭***
<sub>아래 첨자</sub>
<sup>윗 첨자</sup>
<ins>ins</ins>는 시각적 언더바 뿐만아니라 추가된 또는 변경된 내용 표시 의미
<u>u</u>는 단순 시각적 언더바
**\*\*탈출문자\*\*** \\백슬래시\\
(\는 뒤에 오는 문자를 그대로 출력)
```

**굵게** 또는 **굵게**

_이탤릭체_ 또는 _이탤릭체_

~~취소선~~

**굵게 일부*이탤릭체***

**_모두 굵게 이탤릭_**

<sub>아래 첨자</sub>

<sup>윗 첨자</sup>

<ins>ins</ins>는 시각적 언더바 뿐만아니라 추가된 또는 변경된 내용 표시 의미
<u>u</u>는 단순 시각적 언더바

**\*\*탈출문자\*\*** \\백슬래시\\
(\는 뒤에 오는 문자를 그대로 출력)
